A hidden state is both a prediction and a memory

A token representation is both an answer and a memory. It is decoded into uncertainty about what comes next, while its layer-wise keys and values preserve what future tokens may need.

The highlighted state for “France” first supports uncertainty over what follows. One layer later in the sequence, its cached key and value supply the country context that helps the model predict “Paris.”
