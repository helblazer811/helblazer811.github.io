Looped Transformers: From Sequence Recurrence to Depth Recurrence

A visual explainer by Alec Helbling

Let’s start with the once-dominant relatives of looped transformers: sequence RNNs. These models apply a shared recurrent cell one token at a time, passing a hidden state from one position to the next. Their recurrence runs over token positions.

But what if we kept representations for all tokens and repeatedly updated them together? With self-attention, each token can gather information from the others at every iteration. We can then apply the same attention-based block again, refining those representations recurrently over computational depth rather than sequence position. This is the central idea behind looped transformers, popularized by Universal Transformers.
